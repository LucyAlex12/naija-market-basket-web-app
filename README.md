# Naija Market Basket Web App

Interactive grocery price estimator for common Nigerian market items across sample cities. Users can compare food prices, build a basket, and estimate total spend in naira.

## Run

Open `index.html` in a browser.

## Features

- city selector for Lagos, Abuja, Port Harcourt, and Enugu
- common Nigerian food basket items
- add/remove basket items
- naira totals and price comparison
- browser-only JavaScript with `localStorage`
